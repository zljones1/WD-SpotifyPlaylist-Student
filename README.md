# Mood Mixtape — Spotify Playlist Generator

Student completion of the GCA-Classroom **WD-SpotifyPlaylist-Student** web development assignment.

## What it does
- Select a **mood** (Focus, Chill, or Hype)
- Choose a **mode** (Quick Play = top 3 songs, Full Session = all songs including bonus)
- Dynamically builds a Spotify-style playlist from hardcoded data
- Click any song row to fade it out and remove it
- Milestone messages appear as you clear songs

## Files
- `index.html` — provided starter (do not edit for the assignment)
- `styles.css` — provided starter (do not edit for the assignment)
- `script.js` — **completed** steps 5–10 (mode logic, feedback, DOM creation, click-to-remove, milestones)

## How to run
1. Clone the repo
2. Open `index.html` in a browser (or use VS Code Live Server)
3. Select a mood and mode — the playlist appears below
